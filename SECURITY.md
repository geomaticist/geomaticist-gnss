# Security

Please do not report security problems in a public issue.

Report them privately through GitHub: the repository's **Security** tab, then **Report a vulnerability**
(private vulnerability reporting). Only the maintainer sees the report. You should get a first answer
within a week.

Relevant problems include a crafted RINEX file, raw receiver log or product file that makes the engine
crash, hang, use unbounded memory, or write outside the folder it was given.

Only the latest release gets fixes.
